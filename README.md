# PowerPoint Gesture Control System

## PPT Gesture Control

This project allows you to control PowerPoint presentations using hand gestures. It integrates libraries like **OpenCV**, **Mediapipe**, and others to detect hand movements, enabling actions such as slide navigation, pointer control, and drawing.

## Install Dependencies

Run the following command to install the required dependencies:

```bash

pip install opencv-python mediapipe pyautogui pillow pywin32

```bash
